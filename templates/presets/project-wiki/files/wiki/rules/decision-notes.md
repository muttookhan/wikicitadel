# Decision notes

Starter conventions for a project wiki:

- Every decision lands in the decisions register the day it is made,
  with the basis it rests on.
- A reversed decision is recorded as a reversal, never edited away.
- Each build batch is verified against the thing itself before it is
  reported done.
