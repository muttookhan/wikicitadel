# Code of Conduct

This project's community is small and technical. The whole code is:

- **Be accurate.** Say what you verified, name what you did not, and
  correct the record in place when you get something wrong.
- **Be kind.** Critique pages, code, and claims — never people.
- **Be patient with newcomers.** Everyone's first citation marker is
  malformed.
- **No harassment, no spam, no personal data** — your own or anyone
  else's — in issues, pull requests, or fixtures.

Maintainers may remove contributions that break these rules and, for
repeated or serious breaches, restrict participation. Decisions are
recorded publicly in the thread where they were made.

_Written for this project in plain terms, rather than adopted from a
template, so that every line is one the maintainers actually enforce._
