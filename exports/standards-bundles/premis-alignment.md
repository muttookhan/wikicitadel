# PREMIS alignment — checkpoint + provenance vocabulary

Alignment version 1.0.0. PREMIS Data Dictionary 3.0 (Library of Congress) terms mapped onto the fields this wiki already records. DOCUMENTATION ONLY — no house schema is changed by this alignment (the Round 13 filing's terms). Generated by scripts/wiki_standards_bundles.py from the alignment table in that module — regenerate, never hand-edit.

| PREMIS entity | Semantic unit | House field | Notes |
|---|---|---|---|
| Object | objectIdentifier | repo-relative path (checkpoints.d/<id>.json, evaluation/merkle-manifest.jsonl, a bag's payload paths) | paths are the wiki's object identifiers; the linked-data export derives IRIs from them |
| Object | objectCharacteristics / fixity (messageDigest) | checkpoint line_hash + signature; provenance manifest_sha256 and corpus_root in each checkpoint line; manifest-sha256.txt inside a bag | sha256 throughout, as PREMIS records the algorithm with the digest |
| Object | preservationLevel / storage | retention-policy.json classes (keep-forever vs clocked) and the witness copy outside the repo | class-level only; no per-object preservationLevel is recorded — see gaps |
| Event | eventIdentifier | <checkpoint id>/<event slug>, minted by this generator | derived identifiers: stable because the source lines are hash-chained and immutable |
| Event | eventType | derived from the register line kind + the act it records (creation / fixity check / replication / timestamp anchor) | Library of Congress PREMIS event types where they fit; 'timestamp anchor' is a named local extension |
| Event | eventDateTime | created_utc (checkpoint lines) / attempted_utc (anchor lines) | the record's own datetime, never the generator's clock |
| Event | eventOutcomeInformation | anchor entries' recorded status, verbatim (a failed anchor stays failed); signature presence for checkpoint creation | outcomes are copied, never upgraded — the schema's dual-anchor rule in PREMIS dress |
| Event | linkingAgentIdentifier | signer identity on checkpoint lines (mehmed@llm-wiki); scripts/wiki_checkpoint.py for the acts the tool performs (anchoring, witness copy) | the register records the identity string; agentType is not recorded there — see gaps |
| Event | linkingObjectIdentifier | the checkpoint artefact / the provenance manifest the checkpoint binds | every event also names its source register line by line_hash (the derivation audit trail, a house field riding beside PREMIS) |
| Agent | agentIdentifier / agentName / agentType | signer identity string; the checkpoint tool as software agent for its own acts | no agent register exists; identity is the string on the signed lines |
| Rights | rightsStatement (rightsBasis, rightsGranted) | retention-policy.json classes (how long, what act an expiry names) + sensitivity.json classes (who may read/cite) | policy-level mapping only: no per-object rights statements are recorded — see gaps |
