# Fonts

The Lens ships four open font families, each under the SIL Open Font License 1.1:

- **Atkinson Hyperlegible** — the reading typeface, chosen for legibility.
- **Fraunces** — display headings.
- **IBM Plex Mono** — code and data.
- **Inter** — interface text.

The .woff2 binaries in this directory are the unmodified distributions of those families.
