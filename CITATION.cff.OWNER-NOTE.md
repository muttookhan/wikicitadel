# CITATION.cff — owner note

The generated `CITATION.cff` carries only facts already public in this repository (project name, repository URL, licence, version/date as stated). It OMITS the `authors` field and any `preferred-citation` text: the credit contents of the citation file are the OWNER's decision and await the owner's ruling. CFF 1.2.0 requires `authors`, so `scripts/wiki_cff.py validate` reports the file as not yet valid until the owner supplies the credit contents. No author names were invented to make it pass.
